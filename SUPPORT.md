# Bean Support

Bean is a community-supported public beta.

## Before filing an issue

1. Check [SUPPORTED_APPS.md](SUPPORTED_APPS.md).
2. Confirm Bean is in `/Applications` and Accessibility is allowed.
3. Confirm only one Bean instance is running.
4. Reproduce with a short synthetic sentence.
5. Focus the failing field and choose Bean → Check Current Field from the menu
   bar.
6. Run Settings → Troubleshooting → Copy Diagnostics Summary, or use **Copy
   report and open GitHub issue**.

Open a GitHub issue for reproducible bugs and feature proposals. Include the
Bean version, macOS version, source app/version, action used, expected result,
actual result, and content-free diagnostics. The report includes up to ten recent
operation outcomes but never the text that was processed.

Never post an API key, private text, clipboard contents, provider request or
response body, or a screenshot containing sensitive information.

Security problems must be reported privately according to
[SECURITY.md](SECURITY.md).
