● Bean — Web Inline Beta

Inline proofreading for web text fields. Off by default. Bean requests access only to the exact sites you approve and never stores your text.

Setup
  1. Keep the Bean app in Applications and open it.
  2. In Bean, open Settings → Labs → Browser Extension.
  3. Click Detect and Install, then reload this extension once.
  4. Return here, approve your sites below, and save.

Bean normally detects this extension automatically. If it asks for the ID, copy it here:

Reference sites: Gmail at mail.google.com and Slack web at app.slack.com. Bean supports their ordinary message composers when the exact site is approved. Password, search, email-address, code, disabled, and read-only fields are skipped; Google Docs canvas and Slack desktop use the Mac app instead.

Bean app (Native Bridge)

Provider checks are off by default because they can make a paid API call after typing pauses. The offline detector has no token cost. When enabled, Bean sends only the focused field text and does not store it.

Approved sites

Enter exact hostnames, one per line. Saving asks Chrome for access to only these sites. Removing a hostname revokes its permission.
