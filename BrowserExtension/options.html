● Bean — Web Inline Beta

Inline proofreading for web text fields. Off by default. Bean checks text only in editable fields where you enable it, and never stores your text.

Status

Details & install command

If the bridge says "Not installed": load this folder unpacked, copy the extension ID from chrome://extensions, then run:

scripts/install_native_messaging_host.sh <extension-id>

Re-run after the extension ID changes or you move/rebuild Bean.app.

Works in plain text inputs, textareas, and many contenteditable editors (Gmail, Slack web). Password, search, email, code fields are always skipped; Google Docs and Slack desktop aren't supported.

Bean app (Native Bridge)

Provider checks are off by default because they can make a paid API call after typing pauses. The offline detector has no token cost. When enabled, Bean sends only the focused field text and does not store it.

Sites

Leave the allowlist empty to run on all sites, or list specific hosts (one per line, e.g. mail.google.com).
