Where Bean works

On by default across ordinary text fields. Bean automatically stays out of passwords, search boxes, code editors, buttons, and read-only content.

Add only websites where you never want Bean to appear, one per line.

Checking

AI checks can use paid provider tokens after you pause typing. They stay off until you enable this option. Only the focused field text is sent.

Connection details

Keep Bean open in Applications. If connection needs attention, open Bean → Settings → Browser and choose Repair Connection.
